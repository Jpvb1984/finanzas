# Finanzas

App personal (PWA) para ver a dónde va el dinero: importa estados de cuenta de Scotiabank, American Express, Canadian Tire y Capital One, y muestra los gastos por categoría y por mes.

**Privacidad:** este repositorio solo tiene el código. Los movimientos se guardan en el teléfono (IndexedDB) y nunca se suben aquí.

Instalar en iPhone: abrir https://jpvb1984.github.io/finanzas/ en Safari → Compartir → "Añadir a pantalla de inicio".

Librerías incluidas en `vendor/`: SheetJS (Apache 2.0) y pdf.js (Apache 2.0).
